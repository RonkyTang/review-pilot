AUTOMATION / REPOSITORY

仓库自动审查

为仓库创建 GitLab Webhook。新建 MR、重新打开 MR 或推送新提交时会自动进入审查，同一提交不会重复执行。

WEBHOOK SETUP

GitLab 中只需配置一次

1
保存仓库

平台会生成专属 Webhook URL 和 Secret。

2
添加 Webhook

在 GitLab 项目 Webhooks 中勾选 Merge request events。

3
自动执行

每次新提交按最新 SHA 去重并自动进入队列。
